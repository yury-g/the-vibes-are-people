# Published creative AI skills

Checked September 28, 2026. Screenshots are unaltered captures of the official GitHub pages, linked from the site footer.

- [Anthropic Algorithmic Art](https://github.com/anthropics/skills/blob/main/skills/algorithmic-art/SKILL.md): p5.js generative art, seeded randomness and interactive parameters. Anthropic's [marketplace manifest](https://github.com/anthropics/skills/blob/main/.claude-plugin/marketplace.json) includes it in example-skills. See the [official repository](https://github.com/anthropics/skills#try-in-claude) for installation instructions. The publicly available skill is concrete evidence of the methods its instructions discuss, not evidence that particular artists' work trained an underlying model.
- [OpenAI Image Generation](https://github.com/openai/skills/blob/main/skills/.system/imagegen/SKILL.md): raster image generation/editing for Codex. This is a related visual-production skill, not a like-for-like p5.js algorithmic-art implementation. No dedicated equivalent was identified in the official catalog in this pass.

The project studies visible algorithmic methods and their public histories. It cannot reconstruct a model's private training dataset or prove influence from appearance alone. Resource links imply neither endorsement nor a training-data inclusion claim.
